# Laboratorio SBD-RA1: hotel

Datos sintéticos y código docente propio. Requiere Python 3.11 y Java 17.

1. Instala `requirements.txt` en un entorno virtual.
2. `python generar.py --salida datos --copias 1`
3. `python referencia.py datos`
4. `python analizar.py --entrada datos --salida resultados`
5. `python verificar.py resultados`
6. `python streaming.py --entrada datos --trabajo flujo_01`

Las salidas deben ser nuevas. Consulta la web para la interpretación y ampliación.
MongoDB es una integración opcional con un servidor del aula: instala PyMongo 4.10.1 y proporciona MONGO_URI sin incluir credenciales en entregas.
