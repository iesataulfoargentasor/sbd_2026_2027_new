# 4. Ejemplos de aplicación en la vida real

- **Netflix**: analiza lo que ves para recomendarte contenido en tiempo real.
- **Amazon**: analiza tus compras y búsquedas para personalizar recomendaciones.
- **Bancos**: procesan transacciones en streaming para detectar fraudes.
- **Industria 4.0**: sensores en fábricas que alertan al instante si una máquina falla.
