# 1. Introducción: el valor de los datos

En el mundo actual, los datos son un recurso estratégico.

Cada acción en internet, cada compra, cada medición de un sensor, genera datos.

Pero un dato aislado no tiene valor. Solo adquiere sentido cuando se procesa, integra con otros y se analiza.

**Ejemplo:**

- Dato bruto: “Usuario X hizo clic en un anuncio a las 13:04”.
- Información procesada: “El 60% de usuarios hacen clic en anuncios después de las 13:00”.
- Conocimiento: “Es mejor publicar anuncios por la tarde para aumentar la eficacia.”
