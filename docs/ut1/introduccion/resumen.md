# 5. Resumen del tema

- Los **datos** por sí solos no son útiles; necesitan integrarse, procesarse y analizarse.
- La **integración** se hace a través de procesos como **ETL**.
- El **procesamiento** puede ser en **lotes** (batch) o en **tiempo real** (streaming).
- El **análisis de información** puede ser descriptivo, predictivo o prescriptivo.
- Todo este proceso se aplica en múltiples industrias (banca, entretenimiento, industria).
