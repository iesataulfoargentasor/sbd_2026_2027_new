# 3. Arquitecturas de sistemas de datos (visión general)

Para manejar el ciclo completo de los datos, existen diferentes arquitecturas:

- **Data Warehouse (almacén de datos)**: almacena datos estructurados, optimizado para consultas y reportes.
- **Data Lake**: almacena datos de cualquier tipo (estructurados, no estructurados, semiestructurados).
- **Arquitectura Lambda**: combina batch y streaming en paralelo.
- **Arquitectura Kappa**: todo el procesamiento se hace en tiempo real (streaming).

No es necesario profundizar mucho aquí todavía, solo tenemos que entender que existen estructuras distintas para distintos problemas.
