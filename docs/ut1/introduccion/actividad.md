# 6. Actividad práctica (nivel inicial)

**Inicio con Python:** [Abrir el cuaderno original en Google Colab](https://colab.research.google.com/drive/14JeRxBG1KoCPKAJGbQyWnSoG_NuiLkxJ?usp=sharing){ .md-button }

**Simulación de un flujo ETL muy básico**:

Tenéis que desarrollar, en un cuaderno de GoogleColab, un pequeño flujo ETL muy básico.

1. Se genera un fichero CSV con datos de clientes con errores (fechas en distintos formatos, duplicados, valores faltantes).
2. Los estudiantes deben:

    - Extracción: abrir y leer el fichero (con Excel o Python).
    - Transformación: corregir los errores → unificar formatos de fecha, eliminar duplicados.
    - Carga: guardar el resultado limpio en un nuevo fichero CSV.

3. Finalmente, calcular algo sencillo como:

    - Número de clientes por ciudad.
    - Edad media de los clientes.
    - Esto les da una primera experiencia práctica en cómo los datos brutos se convierten en información útil.
