## Desarrollo

Instala `requirements.txt` y ejecuta `mkdocs build --strict` o `mkdocs serve`. El laboratorio tiene dependencias separadas, instrucciones en su README y comprobaciones para Python 3.11 y Java 17.

La publicación web de este repositorio nuevo requiere configurar GitHub Pages. Las entregas del alumnado se gestionan en Moodle. Consulta fuentes y atribución en los apuntes.
