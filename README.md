## Desarrollo

Instala `requirements.txt` y ejecuta `mkdocs build --strict` o `mkdocs serve`. El laboratorio tiene dependencias separadas, instrucciones en su README y comprobaciones automáticas con Python 3.11 y Java 17 en GitHub Actions.

La publicación usa GitHub Pages mediante Actions desde main. Las entregas del alumnado se gestionan en Moodle. Consulta fuentes y atribución en los apuntes.
